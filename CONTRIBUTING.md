# Contributing to Hack the Bridge SOC

We welcome contributions from students, educators, and security researchers!

## Contribution Guidelines
1. **Student Challenge Scripts:** If you have created a detection script or sensor parser, place it under `examples/sensors/` or open a PR.
2. **Bug Fixes & UI:** Ensure all Flask endpoints continue to pass unit tests (`python -m unittest discover tests`).
3. **Code Style:** Keep Python code PEP8 compliant and well-commented for students.
