# Security Policy

## Responsible Disclosure

This software is used for educational and research simulations in industrial cybersecurity. If you discover a vulnerability or security defect in this codebase:

1. **Do not disclose it publicly in issues.**
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the lead maintainer:
   - **Maintainer:** Fabian Cras (Teacher-Researcher, mboRijnland / CIV Smart Technology)
   - **Email:** fabiancras@gmail.com
3. Please provide a clear description and reproduction steps.
